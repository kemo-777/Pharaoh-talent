# GitHub Pages preview

This folder is a static visual preview only. GitHub Pages cannot run the Node.js/Express backend or PostgreSQL. Authentication, guardian consent, video uploads, messaging, and live data will not work from this preview.

For the full application, publish the repository and deploy the included Render Blueprint (`render.yaml`) after configuring email credentials and reviewing provider costs. Keep frontend and backend on the same origin unless cross-origin session security is deliberately redesigned and tested.
